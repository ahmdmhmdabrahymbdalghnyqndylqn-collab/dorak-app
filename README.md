# دَوْرَك — لوحة المالك

واجهة إدارية عربية RTL لتطبيق إدارة العمارات **دَوْرَك**. المشروع تطبيق React Native حقيقي عبر Expo، وليس صفحة ويب.

## الموجود في النسخة

- لوحة نظرة عامة ببطاقات إحصائية وPie Chart ومخطط تحصيل شهري.
- إدارة الحراس وحالات الحسابات والموافقة والإيقاف.
- عرض العمارات بشكل منفصل مع التحصيل والمتأخرات والرصيد.
- البحث عن السكان وتعديل بياناتهم وإضافة ساكن.
- مسار واضح لاستبدال الساكن مع أرشفة السجل السابق.
- قسم طلبات المشتريات: سوبرماركت وخضار وفواكه ومخبز.
- قسم مستقل للمصاريف: صيانة مصعد، تصليحات ومصروف آخر.
- تصميم متجاوب للهاتف والتابلت، مع شريط جانبي للشاشات الواسعة.
- هوية دَوْرَك بالأبيض والأزرق البترولي `#0F4C5C`.

## التشغيل

يتطلب Node.js وExpo/Android SDK:

```bash
npm install
npm run android
```

## بناء APK

بعد ربط المشروع بحساب Expo EAS:

```bash
npx eas-cli build --platform android --profile preview
```

## ملاحظة الإنتاج

البيانات الحالية تجريبية داخل `src/data.js` لإظهار التصميم والتفاعلات. النشر الفعلي متعدد المستخدمين يتطلب ربط واجهات التطبيق بخادم وقاعدة بيانات ومفاتيح المشروع، وتطبيق صلاحيات المالك والحارس على الخادم.
